# Automated Question Bank Management Portal

A web portal where faculty create, store, search and review exam questions
by subject, topic and difficulty. Built as a DevOps mini project.

## Tech stack
Java 17, Spring Boot, Thymeleaf, H2, Maven, Jenkins, Selenium, Docker, Ansible

## Run locally
    mvn spring-boot:run
Open http://localhost:8081

## Branching rules
- `main`: stable, tagged releases only
- `develop`: integration branch
- `feature/<name>`: one branch per feature, merged through a pull request

## Commit message style
`feat:` new feature, `fix:` bug fix, `docs:` documentation, `chore:` setup/tooling, `test:` tests
